Install the `beholder` command with Homebrew, Cargo, or npm.

## Homebrew

```bash
brew install wyrd-company/tools/beholder
```

## Cargo

```bash
cargo install beholder-cli
```

## npm

```bash
npm install --global @wyrd-company/beholder
```

The npm package is a launcher for the platform-specific Beholder binary.

## Verify

```bash
beholder --version
beholder --help
```
